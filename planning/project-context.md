# Project Context

## Motivation

DecisionForge started as an experiment to compare Jev against
locally hostable decision models.

Initial candidates:

1. StartLux
2. Laya
3. Jev

Jev acts as the non-local reference model.

## Initial Use Case

Classification of contract documents into predefined classes.

Example classes:

- NDA
- Service
- Purchase
- License
- Employment
- Lease
- Amendment
- Termination
- Other

## Future Direction

DecisionForge may evolve from document classification toward:

Input
→ Retrieval
→ Planning
→ Decision
→ Execution
→ Observation
→ Evaluation

A future testing application should use this stack to measure
whether workflows can be completed autonomously and how many
steps and decisions are required.
